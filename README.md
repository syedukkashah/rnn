# rnn
I trained this RNN to understand sequences. It understood suffering instead. A very basic RNN built for educational purposes to learn how recurrent networks, vanishing gradients, and training loops actually work. The architecture is simple, the performance is questionable, and the overfitting is free.


This project uses the IMDb 50K Movie Reviews dataset from Kaggle:
- [IMDb Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
